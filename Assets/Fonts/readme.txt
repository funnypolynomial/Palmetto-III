The font_*.png dump images are from http://www.sealiesoftware.com/palmfonts/ "screenshots of the Palm OS character map from Constructor for Palm OS."
Thanks Greg Parker!

font_graffiti.png is my own work, based on https://en.wikipedia.org/wiki/Graffiti_%28Palm_OS%29#/media/File:Palm_Graffiti_gestures.png
Glyphs resized, edited and in some cases created from scratch.

encode_fonts.py scans the images and extracts 1BPP character data and writes it as FontData.*
*These files are created locally.* They need to be copied up to the sketch directory for inclusion.
